## ⚙️ Dispositivo Automatizado para Abertura de Potes

Projeto desenvolvido como **TCC do curso Técnico em Mecânica**, com o objetivo de auxiliar pessoas com dificuldades motoras na abertura de potes de vidro.

O dispositivo utiliza um sistema mecânico de **garras, molas e redução planetária** para fixar o pote e aumentar o torque disponível para abertura.

O sistema eletrônico utiliza:

- Arduino
- Ponte H
- Motor DC
- Bateria 12V
- LEDs
- Alto-falante
- Interruptores
- Módulo de reconhecimento de voz

O usuário envia um comando por voz, que é interpretado pelo módulo e enviado ao Arduino, responsável por controlar o motor e os demais componentes do sistema.

**Tecnologias:** `Arduino` `C/C++` `Eletrônica` `Sistemas Embarcados` `Mecânica`
